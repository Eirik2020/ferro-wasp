# Interfaces

FerroWasp uses bounded interfaces for pilot input, display, telemetry,
configuration, and debugging.

- [Communication Protocols](communication_protocols.md) introduces SBUS and
  MSP.
- [UART](uart.md) and [UART RX](uart_rx.md) describe the portable serial
  contracts and STM32F4 transport.
- [FerroConfigurator](user/ferro_configurator.md) describes the standard
  Foxeer USB companion application.

The feature matrix in [Current Support](current_support.md) identifies which
interfaces are available on each board.
