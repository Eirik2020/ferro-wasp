# ADR-0042: USB And The Configurator Port Carry One Bounded Command Line

Status: accepted; request routing amended by ADR-0056

Supersedes ADR-0021's read-only clause; its bounded `FWDBG1` status line and
priority placement stand.

Each flight board's USB CDC port, and a UART bound to the `configurator`
function, accept one bounded ASCII command line: configuration get, set and
save, serial port bindings, flash information and the scratch-sector test, log
listing, page reads, sync acknowledgement and erase, and the motor test. The
user chose this command line over expanding MSPv2 (2026-10-08); the MSPv2
configurator stays an opt-in feature, not expanded without approval.

The firmware validates every command and answers on the link it came from; each
link has its own bounded command and response queue into the flash manager.
Writes are refused while armed and verified by readback, destructive commands
need explicit confirmation, and nothing on the command line can arm the craft;
while a USB host is connected, or within 2 s of a configurator-link command,
arming is refused outright (PR #24).
The motor test and the unconditional log erase are USB-only. USB service runs
below the safety, control, IMU, and RC priorities with fixed-size buffers.
