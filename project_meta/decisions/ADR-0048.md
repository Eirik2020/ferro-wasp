# ADR-0048: Bidirectional eRPM Supersedes UART Telemetry For Arming

Status: accepted, not yet implemented; supersedes ADR-0040's eRPM source where bidirectional DShot runs

Where bidirectional DShot (ADR-0045) runs, arming qualification takes its eRPM
from the DShot replies, not from the legacy BLHeli UART manager. ADR-0040's
rules are otherwise unchanged:
- the stop dwell, guarded idle, and 10 ms guard rechecks;
- the 250 ms spin-up grace;
- three consecutive fresh samples between 3,000 and 10,000 eRPM from every
  physical output;
- an abort at 1.2 s, and overspeed aborting after the grace;
- four stops on every abort.

A reply arrives on its motor's own wire, in the window of the frame that asked
for it. Its output identity therefore comes from the lane, not from request
matching. A sample is fresh when it is decoded from the reply to a frame set
started during the qualification. Consecutive samples come from consecutive
frame sets, and a dropped or invalid reply breaks the run.

Betaflight's weaker check, one valid reply per motor since boot or the last
arm, is not adopted.

Temperature, voltage and current come from extended DShot telemetry (EDT),
as in Betaflight. Before guarded idle on every arm attempt, while all motors
are stopped, every ESC is sent command 13 (EDT enable) ten times, under the
existing special-command rules. An ESC acknowledges with reply `0x0E00`, and
after that it interleaves temperature (degrees C), voltage (0.25 V steps) and
current (1 A steps) frames with its eRPM replies.

An EDT reply is not an eRPM sample. It neither counts toward a qualification
run nor breaks one, and the RPM filter keeps its last eRPM through it. EDT
values are observational: a missing acknowledgement or missing EDT frames
never block arming, and an EDT value never changes motor authority.

The Foxeer's ESC, a Foxeer Reaper 55A, runs BLHeli_32. It has supported bidirectional
DShot since 32.7, but EDT arrived only in 32.10. ESCs without a current sensor
send no current frames. The ESC's installed version and the EDT values it
actually sends are confirmed on target before EDT is relied on.

A stored setting, set in FerroConfigurator, selects bidirectional DShot. Each
board owns its default, which stays off until that board has target evidence.
With the setting off, the legacy UART manager and ADR-0040 apply unchanged.
With it on, the UART manager is not needed for arming. It is retired for
temperature, voltage and current only once EDT has been confirmed on that
board, which on the Foxeer frees USART1 and DMA2 stream 5.

The fault-injection image that reports zero eRPM for output 1 is re-pointed at
the bidirectional input. Changing the arming source is an arming change (W6). It
needs the props-off arming checks, that negative image included, and a flight
re-gate.
